## Codebase Patterns
- Database models use snake_case for field names (mapped with @map in Prisma)
- All monetary values use Decimal type with @db.Decimal(10, 2)
- All tables have createdAt/updatedAt timestamps
- Relations use onDelete: Cascade for items, RESTRICT for references
- Indexes added for foreign keys and frequently queried fields
- API responses use camelCase (Prisma models)
- Frontend expects camelCase property names
- Use 'use client' directive for React components with hooks
- Tailwind CSS for styling, no external CSS files
- All pages under src/app/ follow Next.js 14 App Router conventions

## Important Notes
- Los productos importados desde Excel tienen precios en 0 - necesitan actualización manual
- priceType determina qué campo de precio usar: cash→priceCash, debit→priceDebit, financed→priceFinanced
- Transacciones Prisma con $transaction garantizan atomicidad completa
