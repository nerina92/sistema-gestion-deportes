## Codebase Patterns
- Database models use snake_case for field names (mapped with @map)
- All monetary values use Decimal type with @db.Decimal(10, 2)
- All tables have createdAt/updatedAt timestamps
- Relations use onDelete: Cascade for items, RESTRICT for references
- Indexes added for foreign keys and frequently queried fields

## 2026-01-12 20:50 - US-010 Sales Backend API
- **Implementado**: API completa de ventas con validación y decremento automático de stock
- **Archivos creados**:
  - src/app/api/sales/route.ts (POST y GET /api/sales)
  - src/app/api/sales/[id]/route.ts (GET /api/sales/:id)
  - test-sales-api.js (tests con autenticación)
  - test-sales-api.sh (tests alternativos en bash)
- **Learnings para futuras iteraciones**:
  - Transacciones Prisma con $transaction garantizan atomicidad completa
  - Patrón: verificar stock → calcular precios → crear venta → decrementar stock (todo en una transacción)
  - Usar .mul() y .add() de Decimal para cálculos monetarios precisos
  - Errores de negocio lanzados en transacción hacen rollback automático
  - priceType determina qué campo de precio usar: cash→priceCash, debit→priceDebit, financed→priceFinanced
  - Validaciones exhaustivas antes de transacción evitan rollbacks innecesarios
  - Mensajes de error detallados (incluyen producto y variante específica)
  - Importante: Los productos importados tienen precios en 0, necesitan actualización manual antes de poder vender
